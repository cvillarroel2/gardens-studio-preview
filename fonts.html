Gardens Studio — type research · 2026-08-21

Font candidates with a modern energy

Reference: satspace.ltd actually ships Heebo + IBM Plex Sans / Plex Mono / Plex Condensed (pulled from their live Webflow CSS, not guessed from screenshots). That system reads modern because it is engineered: one quiet grotesque doing the talking, a technical mono doing the labelling, nothing decorative. Current Gardens pair for comparison: Fraunces (serif) + Space Mono. Every candidate below is on Google Fonts, so any pick can be vendored locally the same way.

Each specimen: header voice → nav/label voice → body copy from the site.

C — pairings to try first

1 · Space Grotesk + Space Mono — modern headline, zero change to the label voice, one family. 2 · Heebo + IBM Plex Mono — the closest to satspace's actual energy. 3 · Bricolage Grotesque + Fragment Mono — the most character; echoes the flower title's bounce. 4 · Geist + Geist Mono — the coldest/most technical; try it against the Bright palette. Fraunces can stay as an accent (the wordmark row in the header) under any of these.
